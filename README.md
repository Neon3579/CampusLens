# CampusLens

웹프로그래밍 논문대회 프로젝트

Node.js Express + JSON 데이터 CRUD

## 기능 설명

### 1. 사용자 정보 인증 및 저장

사용자의 정보를 인증하고 저장합니다. 이는 사용자가 직접 관여할 수 있는 데이터인 일정 데이터를 식별하기 위해 필수적인 요건입니다.

### 2. 공개 비정형 데이터 크롤링 후 정형화 및 구조화

단과대, 학부, 학과 등 학교 웹사이트에서 공개된 비정형 데이터(이미지가 포함된 공지사항, 이벤트 등)을 Open weights VL Model 을 통해 텍스트 데이터로 정형화 시키고 JSON 데이터로 구조화 시킵니다. 이는 웹서비스에서 공개된 데이터에 접근할 때 시각적 정보 구조 통일화와 개요 제공을 통해 사용자의 인지 단계와 시간을 단축시킵니다.
